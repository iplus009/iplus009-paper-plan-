# Paper Plan by iPlus — Brand Specification

## Brand hierarchy
- Parent / publisher brand: **iPlus**
- Product name: **Paper Plan**
- Public-facing lockup: **Paper Plan by iPlus**
- Tagline: **Make your own PDF better than anyone.**
- Android application ID: `com.paperplan.app`

Paper Plan is an iPlus app and must not be presented as an unrelated standalone publisher.

## Initial app icon
The vector launcher mark uses a folded document sheet, a Paper Plan "P" monogram and a plus accent. The palette is deep charcoal, violet and mint.

## UI identity
- Dark document workspace
- Deep charcoal surfaces
- Violet primary action color
- Mint secondary accent
- Clear typography and compact tool cards

- `app/src/main/res/drawable/ic_paper_plan_foreground.xml`
